# Immo – realistische Immobilien-Investment-Simulation (Neuaufbau)

Trainingsspiel für Immobilieninvestments in Deutschland: Objekte finden, prüfen, finanzieren, kaufen,
bewirtschaften und einen Bestand aufbauen – mit echten Regeln (Bank, Steuern, Mietrecht, WEG) und echten Regionaldaten.

- **Plan:** [`docs/plan/00-MASTERPLAN.md`](docs/plan/00-MASTERPLAN.md)
- **Recherche:** [`docs/research/`](docs/research/)
- **Alter Prototyp:** `index.html` + `root/` (wird in Phase P0 nach `legacy/prototyp-v0/` archiviert)

> Keine Anlage-, Steuer- oder Rechtsberatung. Alle Werte mit Stand und Quelle; Vereinfachungen sind gekennzeichnet.
