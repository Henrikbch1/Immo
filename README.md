# Immo – realistische Immobilien-Investment-Simulation (Neuaufbau)

Trainingsspiel für Immobilieninvestments in Deutschland: Objekte finden, prüfen, finanzieren, kaufen,
bewirtschaften und einen Bestand aufbauen – mit echten Regeln (Bank, Steuern, Mietrecht, WEG) und echten Regionaldaten.

- **Live-Demo:** https://henrikbch1.github.io/Immo/
- **Stand:** [`docs/STATUS.md`](docs/STATUS.md) · **Sprints:** [`docs/plan/11-umsetzung-sprints.md`](docs/plan/11-umsetzung-sprints.md)
- **Plan:** [`docs/plan/00-MASTERPLAN.md`](docs/plan/00-MASTERPLAN.md) · **Recherche:** [`docs/research/`](docs/research/)
- **Alter Prototyp:** `legacy/prototyp-v0/` (Tag `prototyp-v0`, nur Referenz)

```bash
pnpm i
pnpm dev      # http://localhost:5173/Immo/
pnpm verify   # lint + typecheck + test + build
```

> Keine Anlage-, Steuer- oder Rechtsberatung. Alle Werte mit Stand und Quelle; Vereinfachungen sind gekennzeichnet.
